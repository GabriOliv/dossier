# Tag

A square, outlined label in mono caps for status, revision or classification.

**Consumer provides:** one or two words as children and a `variant`: `outline` (neutral, default), `solid` (`signal` fill, the active or current state) or `inverse` (archived, restricted, closed).

- Do: one `solid` tag per group at most; it is the eye's first stop.
- Do: pair the variant with a word that says the state; colour is never the only cue.
- Don't: round it, add icons, or use it as a button.
