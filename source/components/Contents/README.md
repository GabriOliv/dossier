# Contents

A numbered table of contents: `figure` numbers, uppercase `title` section names, a short description in `ink-muted` and an optional page reference, rows on hairline `rule-soft` separators under a `stroke-rule` rule.

**Consumer provides:** `items` (`title`, `description`, `page`, `active`, optional `index`; numbers default to 01, 02, …). Fills its container's width.

- Do: mark the current section `active` when the contents repeat as a divider page; its number turns `signal`.
- Do: keep descriptions to one sentence and section titles to 1–3 words.
- Don't: more than seven sections on one page.
