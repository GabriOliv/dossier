# Redacted

An inline `inverse` bar that stands in for withheld text, sized by character count.

**Consumer provides:** `length`, the approximate number of characters covered (2–40, default 8). Use inside `body`, Transcript lines or FieldList values.

- Do: remove the real text from your data before rendering; this component never takes it, so nothing hidden ends up in the page.
- Don't: use it as decoration or for emphasis.
