# Dimension

A blueprint measure: a hairline with end extension lines, 45° architectural ticks and the value centred above in mono.

**Consumer provides:** `length` in px (the SVG adds 6px each side for the ticks, so offset the thing it measures by 6px), optional `label` (default "<length> PX") and `active`. Place it directly above or below the object it measures.

- Do: use it in the Blueprint theme for wireframes, specs and layout annotations.
- Do: `active` on the one measure under discussion.
- Don't: put labels on the line itself or use it as a divider.
