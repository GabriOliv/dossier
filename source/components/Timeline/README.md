# Timeline

Evenly spaced events on one hairline axis that ends in a triangle pointer: mono position above, square marker on the axis, label and note below.

**Consumer provides:** `events` in order (`at`, `label`, `note`, `active`). Fills its container's width; 3–6 events read best.

- Do: one `active` event, drawn as a larger `signal` square.
- Do: use it for scales that jump (1, 10, 100, 1000); spacing is even, not proportional.
- Don't: notes longer than one short line.
