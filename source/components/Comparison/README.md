# Comparison

Two or three parallel columns weighed against each other: each opens with a `stroke-rule` rule, a mono code, an uppercase `title`, a lead sentence and a list with square bullets.

**Consumer provides:** `columns` (`title`, `lead`, `items`, optional `code` and `active`; codes default to A, B, C). Columns share the container width equally.

- Do: give every column the same structure and a similar number of items so they read side by side.
- Do: mark the recommended or current column `active`; its rule and bullets turn `signal`.
- Don't: use it for more than three options; that is a DataTable.
