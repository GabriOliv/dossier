# Footnotes

Numbered notes under a short hairline rule: signal mono numbers beside `caption` text in `ink-muted`.

**Consumer provides:** `notes` (`text`, optional `id`; ids default to 01, 02, …). Mark references in running text with `<sup class="label ds-ref">01</sup>`. Max width 560px; place at the foot of the page or section.

- Do: keep ids in the order they appear in the text.
- Don't: more than six notes per page.
